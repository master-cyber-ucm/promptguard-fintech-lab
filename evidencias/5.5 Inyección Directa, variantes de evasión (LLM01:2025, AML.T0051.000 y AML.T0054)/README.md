# Evidencia — TFM PromptGuard FinTech

Este repositorio contiene la evidencia visual (capturas de pantalla) referenciada en la memoria del TFM, organizada por el apartado del documento al que corresponde.

## Estructura

```
evidencias_TFM/
├── 5.5_inyeccion_directa_variantes_evasion/
│   ├── vulnerable/      → capturas sobre la versión vulnerable de referencia
│   └── endurecido/      → capturas sobre la versión endurecida (postura proxy-full)
└── 6.3_evidencia_historica_prototipo_run_20260821_201234/
    → capturas del prototipo attack_loop.py (summary.md y log.jsonl)
```

Cada subcarpeta incluye su propio `README.md` con la descripción de cada captura, enlazada al apartado y a la tabla correspondiente de la memoria.
