# Evidencias

Esta carpeta contiene las evidencias obtenidas durante las pruebas realizadas en el marco del TFM, respecto a las variantes de ataques de inyección directa.

Las evidencias incluyen:

* **Capturas de pantalla** de las ejecuciones y resultados obtenidos durante las pruebas.

La estructura de las subcarpetas permite organizar las evidencias según la prueba, experimento o escenario al que corresponden.

Estas evidencias se incluyen como material de apoyo para la documentación y el análisis experimental presentado en el TFM. 

## Contenido

* `capturas/`: capturas de pantalla correspondientes a las pruebas realizadas.

## Nota

Las evidencias corresponden a ejecuciones realizadas durante el desarrollo del laboratorio y se conservan para facilitar la trazabilidad y revisión de los resultados presentados.
